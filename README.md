# AppArmor Customizations for Downloaded Mozilla Apps

This repository contains AppArmor profile setup designed for customized installs of Mozilla products. You may have to adjust paths as necessary in customizations.

## Quick Setup

- `install.zsh` — creates the necessary symlinks and reloads profiles.  
- `uninstall.zsh` — unloads profiles and removes symlinks with confirmation prompts.
